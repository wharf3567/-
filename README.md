## 简介
面对同济大学四平校区学生的校内肯德基点单助手 <br>

## 安装
### Claude Code
```bash
# 安装到当前项目（在 git 仓库根目录执行）
mkdir -p .claude/skills
git clone https://github.com/wharf3567/KFC-order .claude/skills/KFC-order

# 或安装到全局（所有项目都能用）
git clone https://github.com/wharf3567/KFC-order ~/.claude/skills/KFC-order
```

## 使用
在Claude Code中输入：
```
/KFC-order
```

按提示输入点单需求或更新信息

## 编写
