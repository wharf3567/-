# 同济大学四平路校区周边 KFC 门店

## 校内肯德基（主推，默认门店）

| 项目 | 详情 |
|------|------|
| 名称 | 肯德基(同济大学餐厅) |
| 位置 | 同济大学四平路校区**干训楼一楼**，南门附近，宿舍楼下 |
| 开业 | 2024年8月（上海第600家KFC） |
| 面积 | 较小，精致型门店 |
| 品类 | **精简菜单**，比校外标准门店少，部分限定/联名款不供应 |
| 下单方式 | **肯德基APP** → 选择"同济大学校内餐厅" → 到店自取 |
| 会员优惠 | 支持**大神卡**，部分套餐享会员专属价 |
| 营业时间 | 约 7:00-22:00 |
| 高峰时段 | 11:30-13:00, 17:00-18:30 |
| 取餐 | 堂食或自提取走（回宿舍吃） |
| 配套 | 旁边有肯悦咖啡 |

### 校内店常规品类（参考，以APP为准）

- **汉堡**：香辣鸡腿堡、劲脆鸡腿堡、新奥尔良烤鸡腿堡、汁汁双层嫩牛堡
- **炸鸡**：吮指原味鸡、香辣鸡翅、黄金鸡块、热辣香骨鸡
- **小食**：薯条(中/大)、葡式蛋挞、劲爆鸡米花、土豆泥、香甜粟米棒
- **饮品**：百事可乐(中/大)、九珍果汁、柠檬茶、咖啡（肯悦）
- **甜品**：圣代(草莓/巧克力)、甜筒冰淇淋
- **套餐**：OK三件套（工作日）、疯狂星期四特价（周四）、周末疯狂拼
